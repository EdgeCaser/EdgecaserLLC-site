# Edgecaser V3 Fonts

Bundled local webfonts for generated Edgecaser materials.

- Geist: primary display, headings, and body.
- IBM Plex Sans: 08B wordmark and lockups.
- JetBrains Mono: labels, metadata, and technical utility text.

Use `fonts.css` rather than loading Google Fonts at runtime.

These WOFF2 files are the Latin subsets downloaded from Google Fonts for the exact weights
used by the V3 brand system.
